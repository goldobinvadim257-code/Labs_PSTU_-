# Лабораторная работа №2. Сумма ряда

## Формулировка

Найти сумму ряда с точностью ε = 10^-4, общий член которого:

a_n = 10^n / n!

## Результат
Sum = 22025.5

text

Точное значение: 22025.4657948 (совпадает с e^10 − 1).

## Вывод

Сначала задаётся переменная sum для накопления результата и eps —
заданная точность. Затем задаётся первый член ряда a = 10 при n = 1.

Каждый следующий член вычисляется по рекуррентной формуле:
a_n = a_{n-1} * 10 / n

Это позволяет избежать переполнения: n! при больших n растёт очень
быстро, а степени 10^n могут достигать огромных значений. Рекуррентная
формула работает только с текущим членом.

Дальше запускается цикл while, который проверяет, что модуль текущего
члена больше eps. Если да — член добавляется к сумме, номер n
увеличивается, и вычисляется следующий член. Как только модуль члена
становится меньше 1e-4, цикл останавливается и выводится сумма.
