# Задание 1. Вычисление выражения

## Формулировка

Вычислить значение выражения при различных вещественных типах данных (float и double):

((a+b)^4 − (a^4 + 4a^3b)) / (6a^2b^2 + 4(ab)^3 + b^4)

при a = 100, b = 0.001

## Результат
double result = 0.937507
float result = 0

## Вывод

Программа выдала разные результаты, потому что float, в отличие от double,
хранит только 32 бита, из-за чего его точность ограничена 7 значащими
цифрами. Поэтому при больших числах порядка 10^8 (a^4 = 100000000)
разность близких величин у float обнуляется. Double хранит 64 бита и
обеспечивает около 15–16 значащих цифр, поэтому результат получается
корректным.
